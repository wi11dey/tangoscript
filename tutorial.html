TangoScript

a programming language for tango

by Will Dey, for Comparative Literature 120

Welcome to TangoScript—a programming language for Argentine tango! With TangoScript, you canvas
  • plan choreographies in advance,
  • understand how they would look on the dance floor,
  • check for any weight shift issues,
  • and share your choreographies with your partner and other dancers so everyone is on the same page.
When you first open TangoScript, you’ll see a blank text box, and a canvas with an R and an L. This indicates that the couple is in their chosen hold, leader facing follower, with leader’s weight on the left and the follower&rsquos;s weight on the right. The foot holding the leader’s weight is always shown in black, and the foot holding the follower’s weight is always shown in red.

From here, commands can be typed in the text box to start designing your choreography. There is one command per line, optionally followed by a semicolon. For example, try typing salida_basica(1, 8), which means to plot steps 1–8 of the salida basica.

The TangoScript compiler keeps track of both the leader’s and follower’s weight at all times, and if a move is ever requested which is not possible in real life because either the leader of follower’s weight is on the wrong foot, a TangoError will be generated informing you of the issue. Such issues must be resolved by modifying the choreography so that the couple ends up on the proper foot to be able to make your desired move (see commands below for weight change commands).

Choreographies can be saved and sent to your dance collaborators, using the Save button, which will generate a dance.tango file and ask you where to save it. The file is a text file containing all of the commands that make up your choreography.

The following commands are supported:

salida_basica(start, stop)

This executes steps start–stop of the salida basica, inclusive.

cambio_de_peso()

This command causes both the leader and follower to shift their weight to the opposite foot which they are not currently on. This can be seen by the R and L weight indicators flipping. A Cambio de peso annotation is also added to describe what happened.

secret_step()

This command causes only the leader to shift weight to the opposite foot, with the follower not doing anything.

set_arc(angle)

Cause the couple to gradually turn angle° from the vertical on every subsequent step. Can be reset using set_arc(0).

repeat x { ... }

This command repeats the routine (made up of the above commands) in the ... area x times.
